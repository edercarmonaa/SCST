# Componentes de terceros

La publicación incluye los avisos de licencia del runtime .NET. Los paquetes NuGet tienen sus metadatos de licencia en sus distribuciones originales.

| Componente | Uso | Licencia declarada |
|---|---|---|
| ASP.NET Core y EF Core | Web y persistencia | MIT |
| Bootstrap 5.3.3 | Estilos locales | MIT, archivo LICENSE conservado en wwwroot/lib/bootstrap |
| HTMX | Actualizaciones parciales locales | 0BSD, archivo LICENSE en wwwroot/lib/htmx |
| ClosedXML | Lectura y escritura XLSX | MIT |
| PDFsharp 6.2.0 | Generación PDF | MIT |
| SQLitePCLRaw | Puente nativo SQLite | Apache-2.0 |
| SourceGear.sqlite3 | Binario SQLite distribuido por SQLitePCLRaw 3 | Consulte los avisos del paquete nativo |
| xUnit | Pruebas de desarrollo | Apache-2.0 |

Los dos logotipos institucionales son recursos suministrados por el usuario y no se relicencian como código del proyecto. No se incluyen fuentes comerciales. Arial se utiliza desde la instalación Windows del equipo, sin redistribuir sus archivos. El manual institucional y la autorización final de diseño deben validarse por la dependencia.
